# The Geometry of Regressions — Interactive Lab

An interactive guide to the geometric foundations of econometrics. Explore vector spaces and inner products, visualize OLS and GLS projections, and learn about instrumental variables, endogeneity, and GMM through hands-on diagrams and controls. Based on Antonio Cozzolino's work.
